# Windows x64 发行包设计

## 目标

为 Bejeweled-teamwork 提供 Windows x64 的可移植压缩包和安装程序。最终用户不安装 Qt 或 Qt Creator，即可启动服务端、客户端并在局域网内联机。

## 范围

- 目标平台：Windows x64，使用 Qt 6.7.2 MinGW 64 位构建。
- 发行形态：便携压缩包和 Windows 安装程序。
- 运行入口：创建房间、加入房间、独立服务端。
- 网络：TCP `12345`；创建房间连接 `127.0.0.1`，加入房间输入服务端 IPv4 地址。
- 不包含：Windows x86、Windows ARM64、macOS、Android、iOS。

## 设计

### 网络启动

客户端连接参数从配置文件或启动入口获得，不再依赖源码中的固定局域网地址。创建房间入口负责启动本机服务端并连接回环地址；加入房间入口只连接用户输入的地址。服务端已经监听或端口被占用时，入口报告明确错误并停止后续启动。

### 发行目录

发行目录包含客户端、服务端、配置文件、SQLite 数据库、资源文件、Qt DLL、MinGW 运行库、`platforms`、`imageformats`、`sqldrivers` 和多媒体插件。便携包直接压缩该目录；安装程序将同一目录安装到用户选择的位置，并创建快捷方式。

### 构建与验证

构建脚本检查 Qt 6.7.2 MinGW 64 位工具链，分别以 Release 配置构建客户端和服务端，执行 Qt 部署工具复制依赖。验证包括：可执行文件依赖检查、SQLite 驱动存在、服务端端口监听、创建房间本机连接、加入房间局域网连接，以及从干净 Windows 目录启动。
